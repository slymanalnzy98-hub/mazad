# وثيقة لعبة «المزاد»

المرجع اللي تمشي عليه كل محادثة وكل شغل. أي قرار جديد يتسجّل هنا.

## 1. الفكرة بسطر
لعبة أسئلة جماعية بالرهان: تطلع الفئة بدون السؤال، كل فريق يراهن بالسر من جواله، أعلى رهان يجاوب. صح يكسب، غلط يخسر والخصم يقدر يسرق.

## 2. ليش نتميّز
| المنافسين (قولبها، سين جيم، قمنم) | المزاد |
|---|---|
| تختار سؤال وتجاوب | تراهن قبل ما تشوف السؤال |
| معلومات بس | معلومات + جرأة + خداع |
| شاشة وحدة غالباً | شاشة + جوال لكل فريق |
| هوية كويتية | هوية سعودية، أسلوب أركيد مميز |

## 3. القرارات الثابتة
- **الاسم:** «المزاد» يوضح الفكرة. ندرس أسماء بديلة، ولو ما عجبنا شي أفضل نثبّته (ويحتاج فحص علامة تجارية).
- **الأسلوب:** أركيد الثمانينات معتمد، ونطوّره لمستوى أعلى: نص واضح، وحركة وأصوات بكسل.
- **المنصة:** نبدأ بموقع ويب، بس نبني الكود من البداية جاهز يتحوّل لتطبيق (PWA ثم متاجر) بدون إعادة كتابة.
- **السوق:** السعودية أولاً، والخليج بعدين.
- **الإطلاق:** رمضان 1448 (حوالي 8 فبراير 2027).
- **الميزانية الحالية:** صفر. أي تكلفة تنتظر أول دخل. التفاصيل في [دراسة الجدوى](FEASIBILITY.md).

## 4. طرق اللعب
| الطريقة | الحالة |
|---|---|
| شاشة + جوالات في نفس المكان | ✅ شغالة |
| شاشة وحدة بدون جوالات | ✅ شغالة |
| عن بعد (كل واحد في بيته) | ⏳ يحتاج شاشة مشتركة أو صوت |
| أكثر من فريقين (3–4) | ⏳ |
| مع غرباء (مطابقة تلقائية) | 🔜 بعد الإطلاق |

## 5. مسارات الشغل (كل مسار محادثة لحاله)

### أ) اللعبة والبرمجة
- [ ] 3–4 فرق بدل فريقين
- [ ] إعدادات اللعبة: عدد الأسئلة، مدة الجواب، اختيار الفئات
- [ ] إعادة الاتصال لو الجوال طفى أو انقطع النت
- [ ] أوضاع: «كل شي أو لا شي» المطوّر، جولة سريعة، بطولة
- [ ] أسئلة بالصور والأرقام التقريبية
- [ ] قياس الاستخدام (كم لعبة انلعبت، وين الناس تطلع)

### ب) الأسئلة
- [ ] بنك 2000 سؤال للإطلاق، كل فئة 3 مستويات صعوبة
- [ ] مراجعة بشرية لكل سؤال، وزر «بلّغ عن سؤال»
- [ ] باقات: رمضان، كورة، سعودي، عائلي، صعب جداً
- [ ] نقل الأسئلة من الملف لقاعدة بيانات Supabase

### ج) التصميم والتجربة
- [ ] دراسة أسماء بديلة لـ«المزاد»
- [ ] شعار وهوية نهائية
- [ ] صقل كل الشاشات، وشاشة التعليمات
- [ ] أصوات وموسيقى أركيد أصلية
- [ ] تجربة الدخول أقل من 30 ثانية

### د) الربح والدفع
- [ ] أول لعبة مجانية
- [ ] باقات ألعاب + «تذكرة رمضان» لعب بلا حدود طول الشهر
- [ ] بوابة دفع (Moyasar أو Tap): مدى وApple Pay
- [ ] حسابات المستخدمين

### هـ) القانوني والتجاري
- [ ] وثيقة عمل حر أو سجل تجاري (مطلوبة لبوابة الدفع)
- [ ] فحص الاسم كعلامة تجارية
- [ ] شروط الاستخدام وسياسة الخصوصية
- [ ] دومين خاص

### و) التسويق
التركيز على فيديوهات تيك توك وإنستقرام، بثلاث أنواع نجربها ونشوف أيها ينجح:
- [ ] **موشن جرافيك:** شرح اللعبة ولحظات «كل شي أو لا شي»
- [ ] **تجارب ناس حقيقية:** جمعات تلعب وتنصدم وتضحك
- [ ] **تسويق مباشر:** إعلان واضح فيه العرض والرابط
- [ ] **نظام تسويق بالعمولة:** كل مسوّق ياخذ رابط أو كود خاص، ونسبة من كل عملية شراء تجي منه
- [ ] صفحة هبوط
- [ ] حملة ما قبل رمضان
