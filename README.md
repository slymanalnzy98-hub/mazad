# المزاد

لعبة أسئلة جماعية بالرهان: تطلع الفئة، كل فريق يراهن بالسر من جواله، وأعلى رهان يجاوب.

**العب الحين:** https://slymanalnzy98-hub.github.io/mazad/

## كيف تلعب
1. افتح الرابط على التلفزيون أو اللابتوب واختر «شاشة اللعبة».
2. اللاعبين يصوّرون الـQR بجوالاتهم، يكتبون أسماءهم، ويختارون فريقهم.
3. اضغط «ابدأ اللعبة» على الشاشة.

## الملفات
- `tv.html` + `tv.js`: شاشة اللعبة، وهي اللي تدير كل شي
- `play.html` + `play.js`: واجهة الجوال
- `net.js` + `config.js`: الربط اللحظي عبر Supabase Realtime (مشروع MAZAD)
- `questions.js`: بنك الأسئلة
- `mazad.html`: نسخة شاشة وحدة بدون جوالات
- `previews/` و`archive/`: معاينات وأفكار قديمة
