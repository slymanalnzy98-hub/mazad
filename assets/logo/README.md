# شعار «أجل كم؟» (مؤقت)

كل الشعار في مكانين بس، عشان نبدّله بسهولة لما يعتمد المستخدم الشعار النهائي:

| الشي | المكان |
|---|---|
| الكلمة (wordmark) والعلامة (mark) | `AjalIcons.WORD` و`AjalIcons.MARK` في `trial-icons.js` |
| أيقونة التبويب | `assets/logo/favicon.svg` |
| صورة المشاركة (واتساب) | `og.png` (تنولّد من `og.html` بكروم: 1200×630) |

بعد التبديل: زيد رقم `?v=` في `trial.html` و`trial-team.html`، وولّد `og.png` من جديد.
